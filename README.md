# Модель матчей и турниров

Симулятор футбольных матчей и турниров. Сила клубов берётся из рейтинга Opta. Можно разыграть один счёт, серию одинаковых матчей или целый турнир — один раз и много раз.

Живая версия: [tournaments.kotelok.space](https://tournaments.kotelok.space)

Откуда модель и индекс справедливости: [«Финты справедливости»](https://habr.com/ru/articles/913006/) на Хабре.

Канал: [kotelok](https://t.me/kotelok_longread)

## Что можно сделать

Четыре вкладки:

- **Один матч.** Случайный счёт двух клубов. Видны ожидаемая разница мячей, разброс и шансы победы, ничьей и поражения ещё до розыгрыша.
- **Много матчей.** Та же пара много раз. График показывает, как часто первая команда выигрывает в один мяч, в три, играет вничью или проигрывает.
- **Один турнир.** Протокол и таблица. Форматы: на вылет, круг, группа и плей-офф, швейцарка.
- **Много турниров.** Карта мест: как часто каждая команда занимала первое, второе и дальше. Рядом индекс справедливости — одно число о том, насколько итог совпал с силой клубов.

Готовые наборы: топ-8 и топ-32 мира, Английская Премьер-лига, Ла Лига, Бундеслига, Серия A, Лига 1. Свой список собирается поиском по каталогу. Рейтинг в модели можно поправить руками.

У полей есть знак вопроса: там коротко написано, что означает состав, погода, посев, усталость и индекс справедливости.

## Запуск у себя

Нужен Python 3.8 или новее.

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
streamlit run ui/streamlit_app.py
```

Файл рейтингов `opta-power-rankings.csv` в репозиторий не входит. Положите его в корень проекта, рядом с `settings.yaml`. Без него приложение не найдёт клубы. Колонки, которые читает каталог: `team_id`, `team_name`, `start_rating`, `opta_rating`, `country`, `league`, `opta_rank`.

Проверка библиотеки и факторов:

```bash
pytest
```
